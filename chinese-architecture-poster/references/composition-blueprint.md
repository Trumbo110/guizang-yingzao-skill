# 海报构图蓝图

每次生成前填写本蓝图。目标是把“高级、丰富、有层次”等审美形容词转换成图像工具可以执行、验收者可以检查的空间关系。

先记录已选机制，避免无理由拼接：

| 已选要素 | 来源参考/机制 | 在目标照片中解决什么问题 | 与其他要素为何兼容 | 舍弃的候选 |
| --- | --- | --- | --- | --- |
| 基础构图 |  |  |  |  |
| 建筑提取 |  |  |  |  |
| 主/辅助材质 |  |  |  |  |
| 字体系统 |  |  |  |  |
| 颜色逻辑 |  |  |  |  |
| 空间冲突 |  |  |  |  |
| 可选插入层 |  |  |  |  |
| 外来机制转译 |  |  |  |  |

只允许一个基础构图和一个主要空间冲突。无法说明兼容理由的要素不进入蓝图。

若来源是外国建筑、纯外文或异国纹样参考，补填：

```text
原参考只保留的视觉机制：
目标照片中的几何对应物：

必须删除的外国地名、建筑、符号、品牌、人物和广告：
目标建筑独有锚点（至少 2 个）：
```

## 1. 内容与事实

```text
对象：
对象属性：历史建筑 / 修复重建 / 当代院落 / 仿古建筑 / 其他
已确认地点：
已确认事实：
事实来源与级别：VERIFIED / OBSERVED / USER-CONFIRMED
信息模式：主题文字（默认） / 解释注释（仅按用户要求）
主标题：
地点标签：
结构性大字：
主题词或资料文字：
禁用或未确认文案：
```

结构性大字必须有真实含义，但允许因遮挡而不完全阅读。资料文字必须逐字可读，不允许用乱码模拟设计。

将文案分成 `必须出现`、`可选`、`不出现` 三组。若一个信息既不提升身份识别、事实语境、方向、尺度或叙事，就删除。

使用百分比或具体像素填写：

主要对齐线：

受控破格点：最多 2 个
主体容器机制：无 / 字窗 / 连续竖窗 / 同轴多窗 / 模块拼贴（只选一个）
背景尺度机制：无 / 来源正文场 / 重复短地名 / 尺度数字（只选一个）

| --- | --- | --- | --- | --- | --- | --- |

|  | 地点标签 |  |  |  |  | 前景 |

检查：两个表现型字体不能位于同一语义层争夺注意力；书写体不能承担正文；结构性大字允许低对比和遮挡，资料文字不允许。

```text

```

## 4. 建筑提取与材质分区

先写身份保护区，再写处理区域：

```text
身份保护区：
抠图边界：保留哪些屋面、墙体、树、水面和前景
深色实景/双色区域：
网点区域：
线稿区域：
平滑照片区域：
需要压低或移除的背景：
天空/背景相对原图至少改变的两项：色场 / 明度分区 / 材质频率 / 环境简化 / 边界
多窗共同底图与拼合轴：
纹样来源构件、重复单元、使用区域与覆盖比例：
图纸/旧照来源；若无来源则标为轮廓回声：
```

至少使用两种不同的建筑表达材质，但要共享同一真实轮廓。例如实景双色层与对齐线稿层、细网点主体与平滑水面。材质变化应对应结构或叙事边界，不能随机切片。

## 5. z 轴层级栈

从后向前逐层写清楚：

| z | 内容 | 明度/颜色 | 材质 | 与相邻层的关系 |
| --- | --- | --- | --- | --- |
| 0 | 背景纸 |  | 低频纸纹 |  |
| 1 | 结构性大字/色块 |  | 平滑或低对比 |  |
| 2 | 建筑辅助材质层 |  | 线稿/网点 |  |
| 3 | 建筑主层 |  | 双色照片/剪影 |  |
| 4 | 前景标题/标签 |  | 实色文字 |  |
| 5 | 可选功能线/索引 |  | 仅解释注释模式 |  |

层数不是越多越好，但至少有三层能通过遮挡被肉眼辨认。

## 6. 遮挡图

必须填写至少两条：

```text
A 被 B 遮挡 __%，发生在 __ 区域，作用是 __。
C 压在 D 上方，重叠 __%，但避开 __ 身份保护区。
```

推荐范围：

- 建筑遮住结构性大字约 15%–40%，文字仍可凭上下文识别。
- 建筑遮住主标题约 5%–12%，只发生在字脚或局部笔画。
- 前景标签压住低信息墙面约自身面积的 10%–30%。
- 不遮挡超过 20% 的主屋脊、塔刹、牌匾或唯一入口。

### 重叠契约

每一处重叠都要填写，不能只写“叠字”或“文字压建筑”：

| 前层 | 后层 | 共同轴线/网格关系 | 重叠范围 | 视觉任务 | 禁止覆盖 |
| --- | --- | --- | --- | --- | --- |
|  |  |  |  |  |  |

若两元素没有共享边线、基线、栏位、主导轴或明确的遮挡轮廓，它们只是碰撞，不是有逻辑的重叠。

## 6A. 信息模式编译

### 主题文字模式（默认）

| 事实短词 | 来源 | 字体角色 | 栏位与基线 | 色彩/反白 | 与建筑或其他文字的关系 |
| --- | --- | --- | --- | --- | --- |
|  |  |  |  |  |  |

此模式不填写目标构件和引线路由。年代、门名、构件名、方位或地点词只作为真实的排版材料；通过尺度、字重、字距、色相、反白、留白和遮挡分组。关闭所有规则线、边框、引线、下划线、箭头和端点。

### 解释注释模式（用户明确要求时）

| 标签 | 信息类型/来源 | 文字框栏位与基线 | 目标构件 | 路由与折点 | 终点 | 禁穿区 |
| --- | --- | --- | --- | --- | --- | --- |
|  |  |  |  |  |  |  |

规则线和引线不得进入任何文字边界框。为每个文字框向外扩张安全区：资料字至少 `0.5em`，展示字至少 `0.25` 个字高。除非先定义蒙版与 z 顺序，否则线穿字直接判失败。

## 7. 色彩与材质分离

| 区域 | 基础色/明度 | 主材质与频率 | 边缘处理 | 必须区别于 |
| --- | --- | --- | --- | --- |
| 天空/背景纸 |  | 低频纤维/平滑色场 |  | 建筑主体 |
| 建筑屋面 |  | 高频网点/线刻/套印 |  | 天空、墙体 |
| 建筑墙体 |  | 平涂/中频颗粒 |  | 屋面、前景 |
| 环境/现代城市 |  | 低对比网点/去饱和 |  | 主体建筑 |
| 树木/前景 |  | 剪影/粗颗粒/实景 |  | 建筑主体 |
| 水面/玻璃/金属 |  | 可选平滑实景 |  | 粗颗粒层 |
| 强调文字/图形 |  | 相对平滑 |  | 纸面与主体 |

检查：

- 建筑主轮廓与背景要有明显明度差；明度接近时，用色相或描边补足。
- 强调色至少连接两类元素，例如背景色块与标题，或描边与年份，不能只出现一次。
- 纸纹使用低频、低对比纹理；建筑网点使用更高频率；平面色块保持相对光滑。
- 同一张统一噪点不能覆盖所有层。
- 区域纹样只能进入指定 1–2 个遮罩区；方向性纹理必须顺着真实坡面、瓦垄、砖缝或木纹。
- 若强风格化后天空和背景仍保留原图的色相、摄影渐变与细节，仅多一层纸纹，判为未完成。

## 8. 生成策略

选择一种：

### A. 前端排版垫图 + 整体重绘（默认）

复杂字体、跨栏和遮挡默认使用。通常选择 `layout-only`：只用中性占位形状表示建筑范围，不嵌入原照片；只有用户明确要求保留摄影质感时才使用 `photo-overlay`。在 HTML/CSS、SVG 或 Canvas 中以真实字体排出近似成品，输出一张带网格的检查图和一张不带栏线的垫图。主题文字模式的垫图同时关闭全部功能线。把原照片与垫图作为两个独立输入交给图像模型，让模型继承文字边界框、共享边线、换行与遮挡方向，并依据独立的材质方案处理建筑、天空、环境和前景；不在结果上默认重新叠字。

### B. 纯提示词单次合成

只在文字很少、没有复杂对齐或快速草图时使用。提示词必须完整写入网格占位、z 轴层级和遮挡图；不能只写风格名称。

## 9. 失败检查

出现任意一项就重新设计，而不是继续加装饰：

- 标题和照片分别占据上下两个互不相交的矩形区域。
- 所有文字处在同一个前景平面，没有任何被遮挡的大字。
- 建筑、背景和色块共享同一种颗粒或对比度。
- 强调色只用于一根短线、一个年份或孤立小图标。
- 网格只被画成细线，却无法解释元素的起止位置。
- 主题文字模式仍出现可见规则线、构件指向、箭头、端点或编号科普。
- 分割线或引线穿过文字，或从字形内部出发。
- 两个元素发生重叠，却没有共同轴线、前后顺序或视觉任务。
- 注释没有唯一目标，或标签内容与照片可见构件/可靠资料无关。
- 建筑仍是一张完整矩形照片，边界没有参与构图。
- 建筑只是未经处理的抠图，或只有统一纸纹；天空、背景与前景仍保留原照片的连续色调和同一材质。
- 页面出现卡片、胶囊、按钮、投影容器或均匀分布的网页组件。
- 角落出现无法说明主题来源和构图任务的孤立元素。
- 为了丰富而加入伪二维码、乱码、假印章或无意义英文。
- 同时使用两个主体容器机制、两个背景尺度机制或两个语境材料层。
- 字窗/多窗只裁图，没有对窗内建筑进行限色、明度压缩和区域材质处理。
- 字窗吞掉全部身份锚点，多窗无法沿共同轴线拼回同一建筑，或纹样覆盖塔刹、匾额、主檐等身份区超过约 15%。
- 来源正文场使用虚构古文，尺度数字没有可靠来源，随形文字没有真实路径。
- 隐去中文地名后，画面仍主要依靠外国地名、异国纹样、宗教符号、旅游徽章或原参考配色才能成立。
