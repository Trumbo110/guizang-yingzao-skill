## 照片诊断

- 画面是夜间仰视侧立面，两座钟楼一高一低，形成比严格对称更有节奏的双峰构图；十字架、拱券和塔帽是身份锚点。
- 黑色天空占据上半部大量负空间，适合承接低对比的大号年份与拉丁结构字，但不能让文字脱离塔身变成“上文字、下照片”。
- 下部树木遮挡礼拜堂主体，是现场空间层次，不应清空；应把绿叶与橙黄景观灯压缩为深松绿粗网点和琥珀色底光。
- 建筑目前是偏青白的连续摄影明暗，十字架高光略溢出。需要保留真实光源方向，同时将浅色砖墙转译为骨白、青灰和冷绿的丝网套色，拱口内保留暖琥珀光。
- 两座塔体不能使用相同的均匀噪点：近处高塔要有更密的砖纹、檐口线刻与套印边，远处矮塔应稍降对比和频率，建立前后关系。

## 要素混搭

| 要素 | 选择 | 理由 |
| --- | --- | --- |
| 基础构图 | 不对称双塔纪念碑 | 直接沿用照片中一高一低的主次关系 |
| 建筑提取 | 保留两座钟楼、原有十字架、塔帽、拱口与下部树木遮挡 | 身份靠真实比例与构件位置建立，不做幻想重建 |
| 主材质 | 骨白 / 青灰 / 冷绿三阶丝网印刷，局部砖纹线刻 | 与黑夜拉开明度，同时明显脱离原始照片 |
| 辅助材质 | 深松绿粗网点树冠 + 琥珀色滚筒漏印底光 | 与建筑的高频细节形成远近差 |
| 字体系统 | 宋体中文主标题、Bodoni 年份与副标题、窄体无衬线结构字 | 三种角色明确，不随机混字体 |
| 颜色逻辑 | 墨青黑夜、骨白石墙、冷青阴影、琥珀灯光 | 来自原照，但压缩成有限套色 |

## 网格与对齐

- 画布：1536 × 2048，3:4 竖版。
- 六栏；外边距 72px；栏宽 215.333px；沟槽 20px；32px 基线。
- 高钟楼跨第 2–4 栏，矮钟楼跨第 4–6 栏；两塔底部落入同一前景暗部，但顶部保持原照高差。
- `1906` 从左出血跨第 1–6 栏，位于两塔后层；高塔与十字架遮住中部数字，仍应保留两侧可辨片段。
- `SACRED / HEART / CATHEDRAL` 从第 2 栏起形成三级阶梯，全部位于塔后，不与中文标题互相叠字。
- `圣母圣心堂` 沿第 1 栏竖排，位于前层，只允许压住高塔最左侧的低信息边缘约 5%–8%，不能遮挡十字架、拱口和塔帽轮廓。
- `大同古城`、中文主题词与英文主题词共享第 2 栏左边线，落在深色树冠上；三行各自占一条清晰基线，不允许分割线横穿。
- 地址小字以右边距为共同右边线，不另开卡片或信息栏。

## 重叠契约

1. `1906` 与拉丁结构字在后、两座钟楼在前；共享第 2–6 栏，建筑遮挡文字约 20%–45%，形成纵深而非随机叠字。
2. 中文主标题在前、建筑边缘与天空在后；只覆盖高塔最左外缘的低信息区，不触碰两座十字架、塔帽、拱口和檐口转折。
3. 下部主题词完整落在深松绿树冠上，文字之间不互相穿插，不添加任何穿字横线、引线或标注点。
4. 所有可读小字都属于网格同一左边线或右边线；低对比结构字允许被建筑挡住，可读信息不允许被挡。

## 材质图

- 天空：墨青黑纸面，低频纤维与轻微靛蓝滚筒不匀；不是纯数码黑，也不添加星空或云。
- 高钟楼：骨白、冷青灰、深墨绿三阶；砖墙与檐口使用高频线刻 / 网点，大片墙面使用中频丝网套色。
- 矮钟楼：沿用相同色相，但降低一档对比与纹理频率，保持真实远近和高差。
- 十字架与拱口灯光：暖骨白和琥珀两阶，缩小高光晕圈，保留夜间发光但避免数码霓虹感。
- 树木：深松绿和近黑粗网点团块，局部叠一层琥珀漏印；不逐叶描摹。
- 文字：琥珀色年份与竖排主标题；骨白可读文字；冷青灰低对比拉丁结构字。

## 禁止项

- 不画规则线、引线、边框、箭头、下划线、标注点、坐标或可见网格。
- 不做宗教科普、构件说明、编号系统、长段落或说明卡片。
- 不添加新的十字架、圣像、彩窗、人物、烛光、鸽子、地图、二维码、印章或宗教图标。
- 不把原图直接抠出贴到纯色背景；天空、两座钟楼、树木与灯光必须分别完成材质转译。
- 不补出照片中不可见的教堂正立面，不改变两塔的真实高差、宽度、拱口、塔帽和十字架位置。
- 不在生成结果上重新堆叠文字；允许少量字形漂移，但排版关系必须由垫图一次性建立。

## 成图验收

- 两座真实钟楼的不等高关系、拱券、塔帽、十字架和仰视角度被保留，没有变成对称幻想建筑。
- 黑夜为低频纸面，浅色塔体为高 / 中频丝网线刻，树木为低频粗网点并带琥珀底光，三者材质明显不同。
- `1906` 与拉丁字在建筑后层，竖排中文标题在前层，底部主题词由树冠承托；所有重叠都有共享栏线和明确前后关系。
- 没有规则线、标注、网页卡片、随机装饰或额外宗教符号。
- 生成结果保留了高塔在左、矮塔在右的真实高差与两座塔的侧立面细节；十字架的光晕被压缩为印刷式暖光，没有新增正立面或第三座塔。
- `1906`、`SACRED / HEART / CATHEDRAL`、竖排 `圣母圣心堂` 与底部主题词维持了垫图的前后层和共同边线；少量拉丁字被建筑挡住属于设计目标，没有在成图上重新堆字。

## V2 背景综合色相修订

用户指出 V1 虽已更换纸张材质，但墨青黑背景在综合色相和明度上仍接近原始夜空。V2 只修订这一变量，不重做排版：

- 将全部天空负空间从墨青黑替换为氧化朱砂 / 陶土色纸面；不保留黑色夜空、暗角或向黑色过渡的渐变。
- 将 `1906` 与竖排主标题改为深石油绿黑，利用综合色相对比继续承担强调角色。
- 塔体改为暖骨白墙面、冷青灰阴影和深绿黑拱口；十字架保留小范围暖白印刷光晕。
- 树冠继续使用深松绿粗网点，成为画面中唯一的大面积暗部；琥珀底光只存在于树冠内部。
- 网格、文案、双塔尺寸、文字—建筑遮挡和所有保护区均沿用 V1。

V2 验收：

- 缩略图第一眼读到的是朱砂色编辑海报，而不是黑夜照片的印刷版本。
- 背景、建筑、前景形成朱砂暖色、骨白 / 青灰、深松绿三段明确分色。
- 双塔真实高差、侧立面、塔帽、十字架、拱口和树木遮挡未因背景替换而漂移。
- 最终文件：`datong-sacred-heart-cathedral-typographic-v2.png`。
