# 既下山·大同：模板化分析与逻辑混搭 v3

这份案例展示 skill 如何从参考图抽离机制，再依据目标照片重新组合。它不是一张固定模板的说明，也不把参考图中的建筑、人物、品牌或装饰搬进结果。

## 1. 目标照片诊断

### 对象与事实边界

- 对象：既下山·大同酒店。
- 地点：大同古城东南邑。
- 属性：当代院落酒店，不是古代遗存。
- 已核实但不必全部上画面的资料：建筑设计 goa 大象设计、竣工年份 2025。
- 海报第一层只需要建立“既下山—大同—东南邑”的地点识别；设计者和年份适合说明文、图注或系列背面，不应为了显得完整而挤入主画面。

### 几何与身份锚点

- 主导轴：严格中轴和单点纵深，水池、入口、门楼共享同一中心线。
- 主体类型：低矮、多进、左右近似对称的当代院落，而非高塔或单体立面。
- 身份保护区：左右屋面坡度与瓦口、中央门楼、两条弧形步道、成对石构、水池边界及倒影。
- 可用负空间：上部天空、左侧暗墙、右上天空/墙面交界、水池两侧铺地。
- 原生色：冷灰瓦、深灰墙、少量暖木色、蓝色水面；饱和度低，适合用砖红作为编辑性强调，而不改变建筑材料身份。
- 风险：照片本身高度对称，若标题和资料也全部居中，会变成安静但模板化的建筑摄影封面。

## 2. 候选要素穷举与删减

### 文案候选

| 信息 | 视觉任务 | 决策 |
| --- | --- | --- |
| `既下山` | 唯一主语义入口 | 必须出现 |
| `大同` | 城市识别与强调色载体 | 必须出现 |
| `东南邑` | 街区定位与左侧竖向锚点 | 必须出现 |
| `DATONG` | 低对比背景骨架，建立尺度 | 可出现，允许被遮挡 |
| `SUNYATA DATONG` | 与中文主标题语义重复 | 删除 |
| `GOA / 2025` | 事实正确，但主画面不需要 | 从海报删除，可留在说明文 |
| 长篇项目介绍 | 会破坏缩略图层级 | 删除 |
| 坐标、二维码、印章、口号 | 无用户需求或叙事任务 | 禁止 |

### 字体角色候选

- `既下山`：高对比现代宋/明体，承担文化与编辑语气；墨黑、横排、大尺度。
- `DATONG`：超大窄体衬线或 Grotesk，低对比、可被遮挡；它是背景形状，不是第二主标题。
- `大同`：竖向窄重黑或粗宋，使用砖红，连接右侧色场与地点语义。
- `东南邑`：中性窄黑体竖排，放在暖白标签上，必须清晰可读。
- 不使用书法体：照片的建筑语言理性克制；再加入强书写动作会和中轴、线稿、巨型拉丁字形成第三个主要冲突。

### 网格与建筑占位候选

| 候选 | 适配判断 |
| --- | --- |
| 中轴院落 + 六栏编辑网格 | 最适合；保留空间纵深，又允许右侧偏置色块破坏完全对称 |
| 半实景分割 | 适合做材质机制，但不宜成为整张画面的左右硬切模板 |
| 中心纪念碑 | 不适合；院落不是垂直单体，强行纪念碑化会损失进深 |
| 侧边切入 + 红圆 | 不适合；会牺牲水池中轴，红圆也没有语境任务 |
| 对角线屋檐 | 不适合；原图最强关系是中轴而非斜线 |
| 多图拼贴 | 单张测试素材不足，且会削弱建筑整体识别 |

### 背景与配色候选

- 背景纸：暖白低频纸纹，承载背景大字和左侧线稿。
- 主体暗部：冷蓝黑；主体中间调：灰蓝。
- 强调色：砖红，来源于大同砖石/城市编辑语境，用于右侧色场、`大同` 和少量连线。
- 结构色：低对比沙金灰，用于 `DATONG`，与暖纸相近但比纸纹更平滑。
- 水面：保留深蓝实景质感，作为粗网点建筑中的安静区域。
- 舍弃大红圆、黄土橙全底和蓝紫渐变：它们分别对应侧切、局部巨像和商业夜游机制，与当前日照院落不匹配。

## 3. 建筑处理推断

### 抠什么

- 不抠一座孤立的“完整建筑”；应提取一个连续的空间系统：左右屋面、中央门楼、树冠、弧形步道、石构、水池与铺地。
- 将天空纸化，让屋面与树冠形成不规则上边界；保留墙体和水池直到底部出血，消除完整矩形照片感。
- 左右最靠近镜头的墙体可以继续作为深色框景，不要裁掉，否则纵深会变平。

### 如何分材质

| 区域 | 处理 | 原因 |
| --- | --- | --- |
| 左侧约 35% 屋面与墙边 | 冷蓝黑实景底 + 精确暖白线稿 | 借用“实景/图纸”机制，强调构造而不平均描边 |
| 中央门楼与树冠 | 细网点双色实景 | 需要保留远景层次和身份锚点 |
| 右侧屋面与墙体 | 较粗胶印网点 | 与左侧精密线稿形成主要材质冲突 |
| 水池和倒影 | 平滑深蓝照片质感 | 以低频、安静表面衬托建筑高频颗粒 |
| 暖白背景 | 低频纸纤维 | 与建筑网点在纹理频率上分层 |
| 砖红色场 | 相对平滑 | 托住右侧复杂轮廓，不与建筑争夺纹理 |

线稿只追踪屋面、墙边、中轴和池边，不追踪树叶、砖缝或随机阴影。网点密度由近到远有变化，不能用同一噪点覆盖全画面。

## 4. 三个组合方案与选择

评分范围 1–5；总分依次为建筑身份、照片适配、元素兼容、空间层次、文字准确、缩略图识别。

| 方案 | 机制 | 分数 | 判断 |
| --- | --- | --- | --- |
| A 中轴编辑院落 | 六栏中轴；右侧偏置砖红场；左线稿/右网点；背景 `DATONG`；四条真实短文案 | 5/5/5/5/5/5 = 30 | 采用 |
| B 实景—图纸双联 | 隐性两栏；中轴两侧硬切实景和线稿；低信息量宋体 | 5/4/4/4/5/4 = 26 | 材质适配，但构图过于安静，容易像单一效果演示 |
| C 对角线屋檐胶印 | 裁出单侧屋檐；橙色负空间；巨型竖题；粗网点 | 3/2/3/4/5/4 = 21 | 舍弃，违背原图最强中轴并丢失酒店空间身份 |

## 5. 最终逻辑混搭

| 已选要素 | 来源机制 | 解决的问题 | 兼容关系 |
| --- | --- | --- | --- |
| 中轴院落基础构图 | 目标照片自身 + 系列编辑网格 | 保留空间身份和纵深 | 六栏中央栏缝与水池中轴重合 |
| 背景超大字 | 塔类参考中的后景文字机制 | 上部负空间不再是独立标题带 | 被真实屋檐和树冠遮挡，退到建筑之后 |
| 实景/线稿分区 | 半实景参考的同轮廓材质切换 | 让当代建构与传统屋面同时可读 | 只占左侧，和右侧网点形成一主一次材质关系 |
| 粗细网点差 | 局部巨像参考的印刷机制 | 建立近远和物质重量 | 水面保持平滑，避免全图同质化 |
| 右侧砖红色场 | 编辑网格的统一强调色机制 | 打破完全对称并托住右檐 | 同色连接 `大同` 和少量规则线 |
| 宋体 + 结构字 + 中性标签 | 参考组中按角色分字的共同机制 | 建立语义、尺度和方向三级信息 | 每种字体只承担一个角色，不竞争 |

主冲突是“严整中轴 vs 右侧偏置红场”；次冲突是“左侧精密线稿 vs 右侧粗网点”。其余元素重复这些关系，不再加入人物、红圆、印章、书写体或底部资料栏。

## 6. z 轴与遮挡

1. 暖白纸面。
2. 沙金灰 `DATONG` 和右侧平滑砖红场。
3. 左侧建筑线稿辅助层。
4. 冷蓝黑实景/网点建筑主层。
5. `既下山`、`大同`、`东南邑`。
6. 少量与网格、池边相连的规则线。

- 屋檐、树冠与门楼遮住 `DATONG` 约 20%–30%，使其成为空间背景。
- `既下山` 的少量字脚进入建筑上边界，但避开中央门楼和主要屋脊。
- `大同` 位于砖红场之前、右檐之后，局部笔画被遮住。
- `东南邑` 标签压住左侧低信息暗墙，避开瓦口和石构。

## 7. v3 删减决定

v2 左下角的 `SUNYATA DATONG`、`GOA / 2025`、附属红白规则线虽然事实无误，但没有继续承担必要任务：名称已经由 `既下山` 表达，地点已经由 `大同` 与 `东南邑` 表达，网格也已由建筑轴线、竖标签和右侧池边规则建立。它们造成第四级信息和局部视觉重量，因此 v3 将整组删除，恢复为深色铺地与墙影。

这次删减不是“做得更极简”，而是让每个留下的元素都能回答：它在传达什么、连接什么、遮挡什么或建立哪一层空间。
