# 太平楼 V4：以排版为主的编辑海报蓝图

## 为什么推翻 V3

V3 使用三张米白卡片、统一内边距、重复编号、矩形底色、按钮式年份和投影。即使网格对齐，它仍然属于网页/信息面板的组件语法：信息被装进独立模块，建筑和文字没有形成一个连续的字体场。V4 删除所有卡片、投影、按钮和胶囊，让层级重新由字号、字重、栏位、留白、反白和建筑遮挡建立。

## 主导机制

- 基础构图：左侧巨大竖排宋体标题 + 右下对角线建筑；参考“巨大文字与建筑互相切入”的机制，不复制参考图内容。
- 字体系统：高对比宋体承担 `太平楼`、构件名和垂直短文；中性无衬线承担地名、编号、英文和资料。
- 尺度关系：主标题约 212px；结构字 188px；构件名 36–40px；资料字 14–20px。靠约 `14:1` 的尺度差制造海报感，不靠容器。
- 空间冲突：建筑对角线切入严整六栏网格；只有建筑遮住低对比结构字和主标题右缘，文字彼此不碰撞。
- 注释语言：裸排文字 + 2px 正交引线；天空用深墨字，建筑暗部用米白反字，同一系统在不同 z 层切换。

## 六栏与基线

- 画布 1536 × 2048，3:4。
- 外边距 94px；栏宽 208px；沟槽 20px；32px 基线。
- 第 1 栏：顶部索引、主标题、底部年代。
- 第 2 栏：地点、英文地点、垂直历史短文。
- 第 3 栏：斗拱注释与通往上层檐下的引线。
- 第 5 栏：屋顶形制、三层三檐、可见匾额反白注释。
- 建筑跨第 2–6 栏并向右、下出血。

## 信息内容

```text
主标题：太平楼
结构字：TAIPING / TOWER
地点：大同古城 · 东部标志性节点；和阳街 × 太平街
短文：太平楼始建于明代，现存建筑为当代复建。
构件：斗拱 / DOUGONG · 托起外檐
形制：十字歇山顶 / CROSS XIESHAN ROOF
节奏：三层三檐 / THREE EAVE LEVELS
照片观察：四海升平
```

## 重叠契约

1. 建筑在结构字前：上部屋脊遮住 `TAIPING` 右侧约 20%，作用是把天空字层压入空间；结构字仍可读。
2. 建筑在主标题前：最上方檐口只切掉 `楼` 右缘约 5%–8%，作用是让标题和建筑咬合；不遮住整个字心。
3. 反白注释在建筑前：`十字歇山顶`、`三层三檐` 与 `四海升平` 直接落在高频深色建筑层上，不使用底框；靠米白色和空白半径保持可读。

## 禁止项

- 无卡片、无圆角、无投影、无按钮式年份、无胶囊标签。
- 无三张等权信息组件；三处注释的字号、颜色和位置随语义与背景变化。
- 规则线不穿字；引线只从文字区域边缘进入沟槽，并落到真实构件。
- 不加入红日、印章、祥云、二维码等通用中国风填充物。
